# P01 · 环境部署

- 教程：https://dg-ai-notes.pages.dev
- Lab：`npm run lab:01`
- 日期：2026-10-01

## 我做了什么

1. `npm install`（依赖已齐）
2. `npm run setup:config` → 生成 / 确认 `config/agent/models.json`
3. 在 `models.json` 配置 OpenAI provider（项目内配置，非 `~/.pi/agent`）
4. `export PI_CODING_AGENT_DIR=$PWD/config/agent`
5. `npm run lab:01` 成功

运行结果：

- 选用模型：`openai/gpt-4`
- Agent 回复：`I'm an expert coding assistant, here to help you with code editing, file operations, executing commands, and more.`

关键路径：`labs/01-hello/index.ts`  
流程：`ModelRuntime.create()` → `getAvailable()` → `createAgentSession()` → `session.subscribe(text_delta)` → `session.prompt(...)` → `session.dispose()`

## 卡点 / 解决

- 无大卡点；用 `PI_CODING_AGENT_DIR` 把配置固定在仓库内 `config/agent/`，避免依赖本机 `~/.pi/agent`
- 注意：`models.json` / `auth.json` 已在 `.gitignore`，勿提交 API Key

## 收获

- Pi coding-agent SDK 最小闭环可跑：配置目录 → ModelRuntime → AgentSession → 流式 `text_delta`
- 默认人设偏 coding assistant（即使 prompt 只要求「一句话介绍自己」）
- 下一步：`npm run lab:02` 观察完整事件流，并填 `P02.md`
