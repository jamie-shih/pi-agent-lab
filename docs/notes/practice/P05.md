## 工具清单

| 名称 | 输入 | 风险 | 状态 |
|------|------|------|------|
| `query_data` | column / operator / value / limit? | 只读 CSV，低 | Lab 05a |
| 内置 read/bash/edit/write | 文件系统 | 高（垂直场景应藏） | `noTools: "builtin"` + `tools: ["query_data"]` |

## 设计取舍

- `defineTool` 一次打包「说明书 + execute」；参数校验 / 错误回传 LLM 由框架做
- `description` 写清何时用、字段边界，比省事文案更重要
- 返回必须 `{ content: [...], details: {} }`（`details` 必填，LLM 看不到）
- 垂直 Agent：先藏内置工具，再只暴露业务工具
